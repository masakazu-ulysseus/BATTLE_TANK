# エンディング画面仕様書

## 背景

v2.1 時点では全35ステージをクリアしても完了ボーナスが加算された後、
通常のゲームオーバー画面に遷移するだけで、達成感のある「エンディング」が存在しなかった。

## 仕様

### 状態遷移

- 新規ゲーム状態 `STATE_ENDING`（= 4）を追加する。
- 最終ステージ（`TOTAL_STAGES`）クリア後の `advance_stage()` で:
  1. `GAME_COMPLETION_BONUS` をスコアに加算
  2. ハイスコアを更新・保存
  3. `STATE_ENDING` へ遷移し、エンディング曲（`musics[3]`、ループ）を再生
- `ENDING_TIMER`（900フレーム = 15秒）満了、または START / 発射ボタンで
  タイトル画面へ復帰する（タイトルBGM再開）。

### 画面構成（上から）

| 要素 | 表示内容 | 演出 |
|---|---|---|
| 祝福タイトル | `CONGRATULATIONS!` | 虹色に変化（8フレームごとに色サイクル） |
| 達成メッセージ | `ALL 35 STAGES CLEARED!` | 白色固定 |
| プレイヤー戦車 | プレイヤースプライト（上向き） | 画面中央に表示 |
| 最終スコア | `FINAL SCORE: nnnnnn` | 白色 |
| 新記録表示 | `NEW HIGH SCORE!` | ハイスコア更新時のみ、黄色 |
| 操作案内 | `PRESS ENTER TO CONTINUE` | 点滅表示 |

### 音響

- エンディング専用のビクトリー曲（`musics[3]`）をループ再生する。
- 詳細は `docs/sound_system.md` を参照。

## テスト観点

- 最終ステージクリアで `STATE_ENDING` に遷移すること
- タイマー満了・ボタン入力でタイトルへ復帰すること
- ハイスコアが更新・保存されること
- エンディング画面の描画がエラーなく行われること
