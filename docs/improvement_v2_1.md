# 改良仕様書 v2.1 — バトルシティー準拠改良

## 目的

本作はバトルシティー（ナムコ, 1985）のクローンだが、本家と比較して劣っている点が多い。
本改良では、本家のゲームデザインに準拠した機能追加・修正を行い、ゲーム体験を本家水準に近づける。

## 詳細仕様

### 1. 被弾時のリスポーン

- 現状: 被弾してライフを失っても、その場で無敵状態になりゲーム続行。
- 改良: 本家同様、ライフを失ったら**プレイヤー開始位置（基地左前）に再出現**する。
  - 位置: `PLAYER_START_GRID_X/Y`、向き: 上、移動状態リセット
  - リスポーン後は `RESPAWN_INVINCIBLE_FRAMES`（180フレーム = 3秒）の無敵
  - パワーレベルは NORMAL にリセット（従来通り・本家準拠）

### 2. アイテムキャリア敵（赤点滅）

- 現状: 各敵が25%の確率でランダムにアイテムを保持。外見では判別不可。
- 改良: 本家同様、**ステージ内で4番目・11番目・18番目に出現する敵**がアイテムを保持する。
  - 定数 `ITEM_CARRIER_SPAWN_ORDER = {4, 11, 18}`（1始まりの出現順）
  - キャリア敵は**赤く点滅**して描画される（8フレーム周期でパレットスワップ）
  - 保持アイテムの種類は出現時にランダム決定（従来通り）
  - `ITEM_CARRIER_PROBABILITY` による確率方式は廃止

### 3. 敵20機・全35ステージ

- `ENEMIES_PER_STAGE`: 10 → **20**（本家準拠）
- `TOTAL_STAGES`: 16 → **35**（本家準拠）。ステージ2以降は既存の決定論的自動生成を使用。

### 4. 敵残数表示

- 現状: 撃破数（KILLED）のみ表示。あと何機出てくるか分からない。
- 改良: 本家のサイドバー（残敵アイコン）に相当する**未出現の敵数 `LEFT:nn`** を下部UIに表示。
  - `EnemyManager.get_unspawned_count()` を新設

### 5. ステージクリア集計画面

- 現状: 「STAGE n CLEAR!」のオーバーレイが2秒表示されるのみ。
- 改良: 本家同様、クリア後に**敵タイプ別の撃破数とスコアの集計画面**を全画面表示する。
  - 各敵タイプのスプライト・撃破数・小計、合計撃破数、ステージボーナス、ライフボーナスを表示
  - 表示時間: `STAGE_CLEAR_TIMER`（300フレーム = 5秒）、START/発射ボタンでスキップ可能
  - `EnemyManager` がステージ内のタイプ別撃破数 `destroyed_by_type` を記録する

### 6. 撃破スコアポップアップ

- 敵を撃破した位置に獲得スコア（例: `100`）を約0.8秒ポップアップ表示（本家準拠）。
- グレネードによる全滅時も各敵の位置に表示する。

### 7. 氷タイル（滑る地形）

- 現状: `TILE_ICE` は定義・描画のみ存在し、どのステージにも配置されず、挙動も通常床と同じ。
- 改良:
  - 移動完了時にタンクの中心が氷タイル上にある場合、**同方向へ滑り続ける**（進行先が通行可能な間）。プレイヤー・敵とも対象。
  - ステージ4以降の自動生成マップに 3x3 の氷エリアを配置（`1 + stage//8` 箇所）。
  - 弾丸は従来通り通過。破壊不可。

### 8. ハイスコア永続化

- 現状: ハイスコアはプロセス内のみで、終了すると消える。
- 改良: `hiscore.dat`（テキスト、整数1行）に保存・起動時に読込。
  - 読み書き失敗時（ブラウザ実行等）は無視してゲーム続行（グレースフルデグラデーション）

### 9. ポーズ機能

- ゲームプレイ中に **Pキー**または**ゲームパッドBボタン**でポーズをトグル。
- ポーズ中は全更新を停止し、「PAUSE」を点滅表示。タイトル画面の操作説明に追記。

### 10. 敵弾数制限のバグ修正

- 現状: 敵の同時弾数制限が `owner_type`（敵タイプ）単位で判定されるため、
  同タイプの敵が複数いると**1機しか弾を撃てない**。
- 改良: `Bullet` に `owner_id`（発射した個体の識別子）を追加し、**個体単位**で1発制限する。
  本家同様、画面上の各敵が独立して攻撃できるようになる。

### 11. 存在しないメソッド呼び出しの修正

- `game_manager.py` が `EnemyManager.cleanup_inactive_enemies()`（非存在、実体は `_cleanup_inactive_enemies`）を
  呼び出しており、`try-except` により AttributeError が握り潰されていた。公開メソッドとして整備する。

## 互換性・影響範囲

- セーブデータ等の永続データは従来存在しないため、互換性問題なし（`hiscore.dat` は新規）。
- スプライトリソース `my_resource.pyxres` の変更は不要（集計画面は既存スプライトを流用、
  キャリア点滅はパレットスワップで実現）。
- ブラウザ版（index.html）はコード変更のみで追従。ハイスコア保存はブラウザでは無効。

## テスト方針

- 静的解析: `pyflakes` 全ファイルパス + `py_compile` 全件成功を必須とする。
- 動作確認（手動）: 以下をユーザー開発環境で確認する。
  1. 被弾時に開始位置へ復活し、3秒間点滅無敵であること
  2. 4・11・18機目の敵が赤点滅し、撃破でアイテムが出ること
  3. 下部UIに LEFT（未出現敵数）が表示され、20から減っていくこと
  4. ステージクリア時に集計画面が表示され、ENTERでスキップできること
  5. 敵撃破時にスコアがポップアップすること
  6. ステージ4以降に氷があり、上を通ると滑ること
  7. ゲーム終了→再起動でハイスコアが残ること
  8. Pキーでポーズ・解除できること
  9. 複数の同タイプ敵が同時に弾を撃てること
